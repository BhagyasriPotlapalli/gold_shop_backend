================================================
GOLD SHOP API DOCUMENTATION
================================================

BASE URL: http://localhost:5000/api
AUTH: Require Header -> Authorization: Bearer <your_token>

------------------------------------------------
1. PROFILES API
------------------------------------------------
This single API manages Vendors, Workers, Bullions, and Processors.
Use the "type" field to clarify which one it is!

METHODS:
GET    /profiles       -> Get all profiles (You can filter via ?type=Worker)
GET    /profiles/:id   -> Get profile by ID
POST   /profiles       -> Create new profile
PUT    /profiles/:id   -> Update profile
DELETE /profiles/:id   -> Delete profile

EXAMPLE PAYLOAD (Send as JSON):
{
  "type": "Worker",       <-- REQUIRED: 'Vendor', 'Worker', 'Bullion', or 'Processor'
  "name": "Ramesh",       <-- REQUIRED
  "phoneNumber": "9876543210",
  "city": "Hyderabad",
  "cashGiven": 5000,
  "goldGiven": 50.500
}


------------------------------------------------
2. ORDERS API
------------------------------------------------
Applies to: /orders

METHODS:
GET    /orders       -> Get all orders
GET    /orders/:id   -> Get order by ID
POST   /orders       -> Create new order
PUT    /orders/:id   -> Update order
DELETE /orders/:id   -> Delete order

EXAMPLE PAYLOAD (Send as JSON):
{

  "customerPhone": "9123456789",
